# VIVSO - Sistema de Gestión de Vivienda Social

**VIVSO** es una solución integral desarrollada como proyecto de integración final para la tecnicatura en desarrollo de software, orientada a optimizar, digitalizar y transparentar la gestión de solicitudes, visitas de obra y adjudicación de viviendas sociales.

---

## 🚀 Tecnologías Utilizadas

El proyecto se compone de una arquitectura modular que incluye:

* **Backend:** 
  * Java 17+
  * Spring Boot
  * Spring Data JPA / Hibernate
  * MySQL / MariaDB
* **Frontend / Mobile:** 
  * React Native / Expo
  * JavaScript / Node.js
